# Student Management System - File Persistence Version

This is the file persistence version of a Java Object-Oriented Programming academic project.

The system manages students, courses, enrollments, grades, attendance, and academic reports using Java classes and file storage.

## Features

- Add students
- Add courses
- Enroll students in courses
- Update grades
- Update attendance
- Display all students
- Display all courses
- Generate reports
- Filter students using lambda expressions
- Sort students and courses
- Load and save data using text files

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstract Classes
- Interfaces
- Collections
- File I/O
- Lambda Expressions
- Sorting and Filtering

## Technologies Used

- Java
- Eclipse IDE
- Text File Persistence
- Object-Oriented Programming

## Data Files

- students.txt
- courses.txt
- enrollments.txt
