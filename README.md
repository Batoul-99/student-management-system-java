# Student Management System - Java

A Java Object-Oriented Programming academic project for managing students, courses, enrollments, grades, and academic reports.

This repository contains two versions of the project:

- File Persistence Version
- Database Persistence Version

## Project Overview

The system is designed for a university environment where students can be enrolled in courses, grades can be updated, and academic reports can be generated.

The project focuses on applying core Java OOP concepts such as encapsulation, inheritance, polymorphism, abstraction, interfaces, collections, file I/O, sorting, filtering, and reporting.

## Versions

### 1. File Persistence Version

This version stores and loads data using files. It uses BufferedReader and BufferedWriter to manage student, course, enrollment, grade, and attendance records.

### 2. Database Persistence Version

This version replaces file storage with database persistence. It stores and retrieves students, courses, and enrollments using database-based relationships.

## Main Features

- Add students
- Add courses
- Enroll students in courses
- Update grades
- Update attendance
- Display students and courses
- Generate academic reports
- Sort students by name and average
- Sort courses by name and number of students
- Filter students by major, average, and enrollment count
